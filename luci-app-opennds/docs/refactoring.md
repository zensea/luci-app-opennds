# 2.0 重构说明

日期：2026-11-06。范围为 `luci-app-opennds/`，目标为 openNDS v11、OpenWrt 24.10、LuCI-JS。项目尚未投入使用，因此删除旧版本兼容和配置迁移功能。

本文的代码量、验证计数和安装包哈希记录首次重构验证快照。后续调整：trustedmac 候选项改为 MAC(设备名)，无设备名时仅显示首个 IP；英文默认提示为 `-- Select a device --`，中文为 `-- 请选择 --`。当前 Node 回归为 92 项；新增 main 推送触发 Actions 构建，更新后的安装包以对应提交的 Actions 产物为准。

提交前移除了仓库外层的 root/，官方源码与插件分别位于根目录的 opennds/ 和 luci-app-opennds/；子模块、Actions、测试与文档路径同步调整。插件内部用于安装文件的 root/ 布局保持原样。

## 实际变化

- 新增共享 `opennds.js`，集中 RPC 声明、总览数据读取、操作禁用、错误通知、成功通知和恢复。同步异常也会恢复控件，重复点击不会再次发送请求。
- 总览页统一首屏和轮询更新，直接保存 DOM 引用，复用卡片外壳、表格单元格和动作按钮。MAC 信任合并使用索引，保留列表顺序与大小写去重；首轮轮询允许页面尚未挂载，避免被同步启动的 LuCI 轮询提前注销。
- 设计器通过七字段定义生成控件、收集 payload、绑定事件；使用真实文本域值初始化，保留多行条款、图标 change 事件、颜色预览及原手机外观，并为标签关联控件。
- 网关配置使用命名的 setup 段；超时、限速和配额使用数据定义。保留主机提示安全处理和 FAS 模式切换状态。
- 删除配置升级 RPC、备份/回滚迁移函数、升级按钮、旧客户端计数格式回退、旧 ucitrack 注册，以及相应失效测试和翻译。
- 状态采集器在一个子进程中读取 ndsctl JSON 和文本元数据，各有 5 秒超时。一路失败保留另一路结果，输出达到 250,000 字节时明确报错。
- 门户头部一次提取七个 JSON 字段，保留五次文案转义、认证参数转义及原生认证回调；缺字段不会继承旧环境变量。
- 包版本更新为 2.0.0-r1，CI 改用统一原生测试入口，包内语法与回归检查包含新增共享模块。

## 调用与性能边界

- 正常运行的一次总览刷新由 4 次 file.exec 请求变为 3 次：PID、合并采集器、日志。
- 门户 header 的 jsonfilter 调用由 7 次变为 1 次；五次文案 sed 仍保留。
- 信任名单查找从嵌套遍历改为索引查找，主要影响管理端浏览器。

这些是调用数量和算法结构的变化。本次没有测量目标路由器上的 CPU、内存或门户 TTFB，不承诺相应百分比的性能提升。
